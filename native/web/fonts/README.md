Typefaces bundled locally from the public assets of https://otzaria.org/plugins
(inspected 2026-10-21), so the desktop store needs no network for rendering:

- `assistant.woff2`: Assistant variable, weights 200–800, body text.
- `vilna.woff2`: OT Vilna regular, display headings.
- `material-symbols.woff2`: the site's subset of Material Symbols Outlined.

The font files are used by `css/site-theme.css`. Fluent SVG icons remain the
fallback for desktop controls and icons outside the site's symbol subset.
